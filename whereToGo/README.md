# 石家庄周边游 · 筛选 & 随机转盘

一个纯前端、单文件的「周末去哪儿」决策小工具：从 131 个石家庄及周边景点里，按城市、类型、距离、天数、关键词、是否免费筛选，随机抽几个，再用转盘决定最终去哪。

> 打开 `index.html` 即可使用，无需安装；联网仅用于「补充新景点」的在线搜索功能。

## 功能

- **多维筛选**：省份 / 城市 / 类型 / 距离 / 游玩天数 / 关键词 / 只看免费
- **随机抽取**：从筛选结果里随机抽 N 个加入「待选区」
- **幸运转盘**：Canvas 绘制，带粒子与指针动画，转出最终目的地
- **联网补充**：本地没有的地点可在线搜索并临时加入（结果存 localStorage）
- **本地记忆**：自定义景点与待选区自动保存，刷新不丢

## 目录结构

```
whereToGo/
├── index.html        # 页面（数据已内嵌，双击即用）
├── attractions.json  # 唯一数据源（改数据只改这里）
├── attractions.csv   # 由脚本导出，供 Excel 查看（勿手改）
├── build.py          # 构建脚本：JSON → HTML 内嵌数据 + CSV
└── README.md
```

## 如何修改 / 新增景点

1. 编辑 `attractions.json`，按下方字段格式增删条目；
2. 运行构建脚本，自动同步到 `index.html` 和 `attractions.csv`：

```bash
python build.py
```

3. 双击 `index.html` 验证效果。

> 为什么这样设计：页面为了「双击即用」把数据内嵌在 HTML 中，但真正的数据源只有 `attractions.json` 一份，避免多份数据各自维护而产生不一致。

## 数据字段

| 字段 | 含义 | 示例 |
|---|---|---|
| `name` | 景点名称 | 河北博物院 |
| `city` | 所在城市 / 区县 | 石家庄市区 |
| `type` | 类型 | 历史人文 / 自然山水 / 古镇古村 / 亲子休闲 / 温泉度假 / 滑雪冰雪 / 美食街区 / 红色教育 / 漂流玩水 / 草原湿地 / 海滨海岛 |
| `features` | 特色简介 | 长信宫灯、金缕玉衣等镇馆之宝 |
| `distance` | 距石家庄市区约多少公里（数字） | 0 |
| `drive` | 自驾约多少分钟（数字） | 15 |
| `days` | 建议游玩天数（0.5 / 1 / 2 / 3） | 0.5 |
| `ticket` | 门票参考 | 免费 / 50元 |
| `isFree` | 是否免费进入（页面筛选用） | true / false |
| `note` | 备注（开放时间、季节、玩法提示等） | 周一闭馆 需预约 |

## 本地预览

- 直接双击 `index.html`（最简单）；或
- 起一个本地服务：`python -m http.server 8000`，访问 http://localhost:8000

## 部署

纯静态页面，可直接用 GitHub Pages 托管（仓库 Settings → Pages，选择分支，或指定 `/whereToGo` 目录）。

## 说明

- 门票、开放时间等信息为整理时的参考值，出行前请以景区官方为准。
- 距离与自驾时长为估算值，实际请以导航为准。
